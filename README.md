# Credit Risk & Loan Decision Engine 💳

An end-to-end machine learning project for predicting loan default risk
and converting probability-of-default estimates into explainable lending
decisions.

## Project Status

🚧 In Development

## Business Problem

The goal is to develop a credit-risk system that estimates the probability
of loan default and converts that prediction into a transparent lending
decision:

- Approve
- Manual Review
- Reject

data quality, human review, and responsible use of automated lending
decisions.
